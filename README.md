# ClipMI — Rilis

Installer ClipMI untuk Windows: aplikasi desktop untuk memotong video kajian menjadi klip vertikal 9:16.

Repo ini hanya berisi rilis (installer). ClipMI yang sudah terpasang memeriksa repo ini setiap kali dibuka, lalu mengunduh dan memasang versi terbaru secara otomatis.

## Memasang

1. Buka halaman [Releases](https://github.com/AndreLimaiDev/clipmi-releases/releases/latest).
2. Unduh `ClipMI-x.y.z-setup.exe`, lalu jalankan.
3. Jika muncul peringatan SmartScreen, klik **More info → Run anyway**. Installer belum ditandatangani secara digital.

Cukup pasang sekali. Pembaruan berikutnya berjalan otomatis, dan bisa juga diperiksa lewat **Pengaturan → Pembaruan aplikasi**.
